# Зертханалық жұмыс №6

## Тақырыбы: Жолдағы сөздердің санын есептеу

### 1. Тапсырманың мақсаты
C# тілінде жолдармен жұмыс істеуді үйрену. Берілген мәтіндегі сөздердің санын есептейтін бағдарлама құру.

### 2. Жеке тапсырма
**1-нұсқа:** Берілген жолдағы сөздердің санын есептеу. Сөздер бір немесе бірнеше бос орын арқылы бөлінеді. Жолдың басында және соңында бос орындар болуы мүмкін.

### 3. Бағдарламаның жұмысы
Бағдарлама пайдаланушыдан мәтін енгізуді сұрайды. Егер жол бос болса, қайта енгізуді талап етеді. Енгізілген жолдағы сөздердің санын есептеп, бастапқы мәтін мен нәтижені экранға шығарады.

### 5. Бақылау сұрақтары

**1. `text[i]` қандай тип қайтарады?**

`text[i]` — char типін қайтарады. Ол жолдағы бір символды көрсетеді.

**2. Неліктен `text[i] = 'a'` деп жазуға болмайды?**

Себебі C# тілінде string өзгермейтін тип болып табылады. Оның ішіндегі символды тікелей өзгертуге болмайды.

**3. Бағдарлама жаңа сөздің басталғанын қалай анықтайды?**

Егер ағымдағы символ бос орын болмаса және `inWord` мәні false болса, жаңа сөз басталды деп есептеледі. Сөздер саны біреуге артады.

**4. Жолдың басындағы бос орындар қалай өңделеді?**

Бос орындар сөз болып саналмайды. Сондықтан жол басындағы бос орындар сөздер санын арттырмайды.

**5. `result += ch` жаңа жол жасай ма?**

Иә. String өзгермейтін тип болғандықтан, қосу операциясы нәтижесінде жаңа жол пайда болады.

### 6. Кездескен қате

Тестілеу кезінде мәтінді бағдарламаны іске қоспай тұрып PowerShell терминалына енгізгенде қате шықты. PowerShell мәтінді команда ретінде қабылдады.

**Шешімі:** Алдымен `dotnet run` командасы арқылы бағдарламаны іске қосып, мәтінді экранда «Жолды енгізіңіз:» деген сұрау шыққаннан кейін енгіздім.

### 7. Жасанды интеллектіні қолдану

### 8. Қорытынды

Зертханалық жұмысты орындау барысында C# тілінде жолдармен жұмыс істеуді үйрендім. `for` циклі, `if-else` шарттары, `bool` типі және жеке әдіс қолданылды. Берілген жолдағы сөздердің санын есептейтін бағдарлама құрылып, тестілеуден өткізілді.
